## Anti-Patterns Verdict
Not obviously AI-generated; passes product slop test. On-brand committed green, avoids cream default, real icon set. Edges generic: Perfil 2x2 journey grid (identical-card template); heavy card reliance.

## What's Working
1. Gradient header system (Home level badge + XP bar; Perfil overlapping progress card) — depth without ambient shadows.
2. "Foco agora" — single clear next step, best-aligned to brief.
3. Lucide icon + tint-tile system — cohesive, mature, avoids emoji anti-reference.
